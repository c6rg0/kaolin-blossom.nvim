# Koalin blossom colour scheme
- Ported from the [emacs-koalin-themes](https://github.com/ogdenwebb/emacs-kaolin-themes)

# Use
'''lua
require("kaolin-blossom").setup({
  italics = {
    comments = false,
    keywords = true,
    functions = true,
    strings = false,
    variables = true,
  },
})

vim.cmd([[colorscheme kaolin-blossom]])
'''
